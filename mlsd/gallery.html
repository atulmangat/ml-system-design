More options

  • Number formats from JSON (bars, matrix): "fmt":"pct" (90%), "pct1" (90.5%), "int" (12,345), "k" (12k, 1.2M), or a template such as "{v} ms".
  • Matrix cell text: "t":[["TP","FN"],["FP","TN"]] overrides the printed value; v still sets the shade.
  • Curve axes: "xticks":[[1,"1"],[10,"10"],[100,"100"]], "yticks" likewise; "xlog":true for a log x-axis (xmin must be > 0). Series label position: "lp": index of the point to label.
  • Embed legend: "legend":[{"t":"Text query","c":0,"m":"c"},{"t":"Video","c":1,"m":"s"}] (marker c, s, t).
  • Ranklist: scores v are scaled to 1 (or "vmax"); show a different label with "sc".
  • Custom hand-drawn SVG that still gets automatic figure numbers: put the SVG in <template id="t-x"> and declare {"type":"svg","tpl":"t-x"}. Use the CSS classes from style.css.
  • Fit pass: nav.js automatically shrinks text that overflows its box and keeps labels inside the diagram. Keep titles short anyway.

Live behaviour (automatic)

assets/live.js is loaded by nav.js and upgrades the drawn diagrams. Authors do nothing extra.

  • Architecture graphs and stacks: data packets flow along every arrow; hover a node to trace its connections and dim the rest; Walk through lights the request path step by step in the order the edges are listed, so list edges in the order data flows.
  • Embedding spaces (embed with a query): drag the query diamond; nearest neighbours (nn) and a "k nearest: cluster x n" readout update live. Give clusters names (n) so the readout is meaningful.
  • Charts (curve): hover for a crosshair with exact interpolated values for every series. Give each series a name (n).
  • Social graphs (net): hover a node to highlight its neighbours and edges.
  • Tooltips: bars, matrix cells, funnel stages and ranked results show their values on hover.
  • Autoplay (GIF-style): assets/motion.js builds each figure when it scrolls into view (bars grow, funnels cascade, stacks rise, matrix cells ripple, curves draw, ranked lists slide in, graphs assemble). While a figure stays on screen it loops a demo: graphs auto-walk their data flow with a step caption, embedding spaces glide the query between clusters, charts sweep the crosshair, social graphs cycle the highlighted neighbourhood. Hovering a figure pauses its loop. Each figure has Replay and (for loops) Pause buttons. Authors do nothing extra; keep edges in data-flow order and name clusters and series.
  • Controls: a Live diagrams switch in the top bar turns the packet animation off (remembered per browser). Motion is also off when the system asks for reduced motion, and animation pauses for diagrams that are off screen.
